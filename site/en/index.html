Three moves and done

All the magic is in three buttons

No half-screen timelines and no hundreds of settings. Select a region, take a screenshot or record, and the file is yours.

01

Screenshot

A screenshot of the screen, a window or a selected region in PNG. Move the frame with the arrow keys, and draw, outline and mask right on top of it.

  • Full screen, a window or a region
  • Arrow, text, brush and shapes
  • Frame adjustment down to the pixel
  • PNG, clipboard or folder
02

Recording

Video from the screen, a window or a region to MKV — up to 2160p and 60 frames per second. Presets, resolution and frame rate are set on one screen.

  • Screen, window or region
  • MKV up to 2160p and 60 FPS
  • System sound and microphone
  • Mouse cursor can be shown or hidden
03

GIF and WebP

A short animation for a chat, an article or a bug report. Presets and a frame-rate control keep the file from bloating.

  • GIF and WebP with one switch
  • Presets like “Balanced”
  • Frame rate up to 60
  • A light file for chat and the web

The details that stick

Capture without extra moves

The things that usually hide behind three menus work on the first click here.

Draw on the fly

Arrow, line, rectangle, highlight, text and color — everything you need to explain a screenshot without words.

A frame that listens

Select a region over the screen and get it right to the pixel — the size is shown on the frame, and the toolbar is always at hand.

Version and licenses in plain sight

The version, the FFmpeg, x264 and Phosphor Icons license texts and a link to the source — all in one About window.

Make it yours

Start with Windows, run from the tray, copy the file to the clipboard and hide the window during capture. Every toggle is remembered.

From frame to file

Three steps and the file is yours

FFmpeg is already inside, so there is nothing to install: Capture Button builds the MKV, GIF or WebP itself.

  1. 1

    Select a region

    A frame over the screen: drag the corners or use the arrow keys to get the size you want.

  2. 2

    Screenshot or record

    A PNG screenshot, an MKV video or a short GIF and WebP animation — in one click.

  3. 3

    Take the file

    The file is already in the folder and on the clipboard: open it, copy it or show it in Explorer.
